# MIS 2027 - منصة الطلبة

نظام جامعي بسيط للمحاضرات الأصلية والشروحات والتبليغات ومواعيد الامتحانات وطلبات الطلاب، مع لوحة إدارة مستقلة.

## الأقسام

- الصفحة الرئيسية: تبليغات القسم والدكاترة، عداد الامتحانات، المواد، وطلبات الطلاب.
- المحاضرات الأصلية: المواد، النظري والعملي، عرض PDF وتنزيل الملفات.
- الشروحات: كل مادة ومحاضراتها وشروحاتها مستقلة.
- لوحة الإدارة: إدارة المواد والمحاضرات والشروحات والتبليغات والامتحانات والطلبات.


## ملفات الشروحات

هذا السلوك خاص بقسم الشروحات:

- عند رفع ملف HTML، يُحفظ الملف الأصلي كما هو بدون استخراج نصوص أو إعادة بناء المحتوى.
- الطالب يستطيع فتح ملف HTML من داخل النظام بنفس تصميمه وCSS وJavaScript الخاصة به.
- يبقى زر تنزيل الملف الأصلي متاحاً دائماً.
- PDF والصيغ التي يدعمها المتصفح تعرض مباشرة كذلك.
- إذا كانت الصيغة لا يدعم المتصفح عرضها مباشرة، يبقى الملف محفوظاً كما هو ومتاحاً للتنزيل.
- يتم تشغيل HTML داخل عارض Sandbox معزول عن جلسة الإدارة لحماية النظام.
- الصيغ التنفيذية والخطرة مرفوضة لأسباب أمنية.

## التشغيل على Windows

1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المشروع.
3. شغّل `ابدأ-MIS-2027.bat`.
4. افتح `http://127.0.0.1:8127`.

في أول تشغيل يتم إنشاء قاعدة بيانات نظيفة وفارغة. بيانات دخول الإدارة الأولى تحفظ في `data/initial_admin_credentials.txt`. غيّر كلمة المرور بعد أول دخول، ثم احتفظ بالملف بمكان آمن أو احذفه.

## قاعدة البيانات والملفات

- قاعدة البيانات: `data/mis_students.sqlite3`
- النسخ الاحتياطية: `data/backups/`
- الملفات المرفوعة: `uploads/`
- الواجهة والشعار: `web/`

لا تحذف `data` أو `uploads` إذا صار عندك محتوى حقيقي.

## الأمان

النسخة تتضمن تشفيراً أقوى لكلمات المرور، حماية CSRF، فحص Origin، Rate Limiting وقفل محاولات الدخول، جلسات محدودة ومحمية، ترويسات أمان، عزل HTML المرفوع، حظر الملفات التنفيذية، Audit Log ونسخاً احتياطية تلقائية. التفاصيل موجودة في `SECURITY.md`.

عند النشر على الإنترنت استخدم HTTPS حصراً وتخزيناً دائماً ونسخاً احتياطية.

## ملاحظة قسم الشروحات
- ملفات HTML تُعرض داخل النظام كما رُفعت، مع المحافظة على التصميم وCSS وJavaScript داخل إطار معزول.
- زر "تحميل الشرح PDF" يحوّل ملف HTML إلى PDF باستخدام Microsoft Edge أو Google Chrome أو Chromium المثبت على الجهاز، مع تفعيل طباعة الألوان والخلفيات والمحافظة على التصميم قدر الإمكان.
- يبقى زر تنزيل ملف HTML الأصلي متوفراً أيضاً.
- هذا السلوك مخصص لقسم الشروحات فقط، ولا يغيّر ملفات المحاضرات الأصلية.
